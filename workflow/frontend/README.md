# Agricultural Field Assessment UI

## Run locally

Install Node.js 18 or newer, then from the `frontend` directory run:

```powershell
npm install
npm run dev
```

Open the Vite URL shown in the terminal (normally `http://localhost:5173`).
The development server proxies `/api` requests to the backend at
`http://127.0.0.1:8000`. Create a production build with `npm run build`.
